## Принятое направление

2026-11-12 пользователь уточнил палитру по фотографии настоящего магазина: графитовый фон вывески, белые буквы и бирюзовый знак. Сайт приведён к этому сочетанию: графитовые шапка, отзывы и футер, светлые нейтральные поверхности, бирюзовые основные кнопки и акценты. Крупная типографика и естественные фотографии сохранены.

Аудитория: местные покупатели цветов и подарков. Основное действие: связаться с флористом и обсудить букет.

Спокойная цветочная мастерская: крупные реальные фотографии, выразительная типографика с кириллицей и свободная композиция. Цвета визуально адаптированы по пользовательскому референсу, это не точные исходные бренд-токены. Логотип использовать из оригинального файла владельца.

Первый экран: фоновое видео сборки букета, лёгкое затемнение, короткий заголовок, одна фраза, кнопки связи с флористом и перехода к букетам. Черновой заголовок: «Для слов, которым нужны цветы».

## Структура

1. Первый экран с видео и основным действием.
2. Подборка из 6–9 реальных работ; цены только после подтверждения.
3. Короткий рассказ о мастерской и флористах с реальными фото.
4. Как заказать: повод и бюджет, обсуждение композиции, получение; окончательный процесс согласовать с магазином.
5. Доставка и самовывоз: только подтверждённые условия.
6. Короткие реальные отзывы со ссылкой на первоисточник.
7. Контакты, режим работы, маршрут и кнопки связи.

## Источники материалов

- Факты: действующая страница, связанная карточка организации, подтверждение владельца.
- Фото работ и мастерской: оригиналы магазина, его VK как источник для отбора; права использования подтвердить.
- Логотип: исходный SVG/PNG владельца; не перерисовывать знак по фотографии вывески.
- Тексты: написать заново по проверенным фактам. Не придумывать преимущества, цены, отзывы, сроки и статистику.
- Видео: основной вариант — реальная съёмка их флориста. Запасные варианты — лицензированный сток или отдельная генерация по согласованному сценарию. Сгенерированное/стоковое видео не выдавать за съёмку сотрудников магазина.
- Выбран сток Anna Shvets / Pexels 5756290. Источник и лицензии перечислены в SOURCES.md, видео размещено локально.

## Видео

Подготовить фрагмент 10–15 секунд: руки выбирают цветы, собирают композицию, перевязывают букет. Мягкий естественный свет, без резких склеек; кадр оставляет свободное место для текста. Для съёмки запросить 30–60 секунд исходного материала и отдельный вертикальный дубль либо достаточный запас для кадрирования.

Встроить как беззвучный цикл с постером и кнопкой паузы. Подготовить лёгкие версии для компьютера и телефона. При запрете автозапуска или сокращении движения показывать статичный кадр.

## Сборка и выпуск

Предложение: собрать здесь, в Codex, отдельный проект `sites/flowers-time`, на HTML/CSS/JavaScript. Для такой визитки это достаточный и переносимый вариант. Sites использовать для демонстрационной публикации; возможность подключения собственного домена предусмотрена инструментами, условия выбранного размещения проверять на этапе запуска. Публичный доступ для клиентов проверить отдельно: новые Sites по умолчанию приватные.

Порядок: материалы и факты → первый экран с выбранным видео → весь сайт → проверка на телефоне и компьютере → демонстрационная версия → правки → открытая публикация и домен.

Проверки: читаемость текста на видео, скорость и объём загрузки, мобильная компоновка, доступность клавиатурой, пауза и reduced motion, работоспособность телефона/VK/маршрута, отсутствие неподтверждённых обещаний, заголовок и описание для поиска и превью ссылки.

Для первой версии предлагаются прямые обращения по телефону и VK. Если понадобятся формы, оплата, корзина или самостоятельное редактирование каталога — определить эти требования отдельно до реализации соответствующих функций.
